# Triage (Linear)

Every comment posted during triage starts with: `> *This was generated by AI during triage.*`

## State mapping (canonical role -> Linear)
| Role | Linear state | Label | Dispatch effect |
|---|---|---|---|
| needs-triage | `Triage` (or `Backlog` if the team has no triage) | `needs-triage` | not dispatched |
| needs-info | `Backlog` | `needs-info` | not dispatched; re-triage on reporter reply |
| ready-for-agent | `Todo` | `agent-ready` | dispatch queue: the orchestrator picks the frontier (all blockers done) |
| ready-for-human | `Todo` | `human` | listed for the user, never dispatched to agents |
| wontfix | `Canceled` (or `Duplicate`) | `wontfix` | closed |

Category: exactly one of `bug` / `feature`. Confirm the team's real state names with `list_issue_statuses` and labels with `list_issue_labels`; if missing, propose them, don't create silently. Exactly one state role per issue; flag conflicts.

Transitions: unlabeled -> needs-triage -> {needs-info, ready-for-agent, ready-for-human, wontfix}; needs-info -> needs-triage after reply. The maintainer may override; flag unusual moves.

## Show what needs attention
Query Linear: (1) issues in Triage with no role label, (2) `needs-triage`, (3) `needs-info` with reporter activity since the last triage notes. Oldest first, counts + one line each; external PRs tagged `[PR]`.

## Triage one issue/PR
1. **Context**: body, comments, labels, dates (PR: diff). Check redundancy (search code by domain concept) and prior rejections (`.out-of-scope/`).
2. **Recommend** category + state with reasoning; wait for direction.
3. **Verify**: reproduce the bug / run the PR's tests. Report confirmed / failed / insufficient detail.
4. **Grill** if needed, using `domain-modeling-linear` to sharpen terms.
5. **Apply** (externally visible, confirm first):
   - ready-for-agent: agent brief comment (current vs desired behaviour, key interfaces by domain name, acceptance criteria, out of scope; no stale file paths) + state/label, with blocking relations set so only the frontier is dispatched.
   - ready-for-human: same brief + why it can't be delegated.
   - needs-info: Triage Notes comment ("established so far" / specific questions for the reporter).
   - wontfix: already implemented -> point to it; rejected bug -> polite explanation; rejected enhancement -> write `.out-of-scope/<concept>.md`, link it, cancel.

## Quick override
"Move ABC-42 to ready-for-agent": confirm the change, apply, offer to write a brief.
